# U.S.O.E. Secure Message Relay

This repository serves as the temporary encrypted message relay for the U.S.O.E. communication system, developed by Okadigbo Studios.

All messages stored here are:
- fully encrypted end‑to‑end,
- formatted using the U.S.O.E. structured message protocol,
- automatically pruned by the client after a defined retention period.

This repository does not contain any plaintext data.  
It functions purely as a lightweight, serverless synchronization buffer between trusted U.S.O.E. clients.

For more information about U.S.O.E., visit the official documentation included within the client application.
